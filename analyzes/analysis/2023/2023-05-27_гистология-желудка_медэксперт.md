# 27.05.2023 — гистология желудка с выявлением H. pylori (МЕДЭКСПЕРТ)

**Метод:** гистологический. **Окраски:** гематоксилин и эозин, Helicobacter pylori.

| Название/показатель | Результат |
| --- | --- |
| Макроскопическое описание | 3 фрагмента серой ткани диаметром по 0.1 см |
| Обсеменение Helicobacter pylori | не обнаружено |

## Микроскопическое описание

Фрагменты слизистой желудка с очаговой атрофией, очаговой гиперплазией
покровно-ямочного эпителия, со слабо выраженным диффузно расположенным
лимфоцитарно-макрофагальным воспалительным инфильтратом, слабым очаговым фиброзом
собственной пластинки. Гистохимия: при окраске толуидиновым синим обсеменения
Helicobacter pylori не выявлено.

## Заключение

Морфологическая картина хронического очагово атрофического слабо выраженного
неактивного гастрита с гиперплазией покровно-ямочного эпителия, слабым очаговым
фиброзом собственной пластинки. Обсеменение Helicobacter pylori: не обнаружено.
