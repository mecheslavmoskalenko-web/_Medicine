# 23.01.2020 — УЗИ щитовидной железы и мягких тканей (Санаторий Кирова)

## Щитовидная железа

| Параметр | Значение |
| --- | --- |
| Расположение | Обычное |
| Контуры | Ровные, чёткие |
| Капсула | Не уплотнена |
| Васкуляризация | Не изменена, Vmax = 4.0–6.0 см/с, RI = 0.5 |
| Эхоструктура | Однородная, равномерно средней эхогенности |
| Правая доля | 4.2 см³ |
| Левая доля | 4.1 см³ |
| Объём | 8.3 см³ |
| Узловые образования | Не определяются |
| Регионарные лимфоузлы | Не увеличены, эхоструктура не изменена |
| Паравазальные пространства | Без особенностей |

**Заключение:** без очаговой УЗ-патологии. Объём железы в пределах возрастной/весовой нормы.

## Мягкие ткани

В проекции визуального дефекта и пальпируемого подкожного уплотнения у угла нижней челюсти слева:
подкожно в ПЖК, над мышечной фасцией, образование овальной формы с чёткими контурами,
однородной структуры, местами ограниченное капсулой, при ЦДК аваскулярно. Размер 10×11×8 мм.

**Заключение:** по эхоплотности вероятно атерома / подкожная фибролипома.

## Требует уточнения

- Судьба образования у угла нижней челюсти после 2020 года в архиве не отражена.
