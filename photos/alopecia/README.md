# Фотодокументация: алопеция

Папка для фотографий очагов гнёздной алопеции.

## Соглашение об именовании

`ДД-ММ-ГГГГ краткое описание.jpg`

Примеры:
- `22-08-2026 очаг усы.jpg`
- `22-08-2026 волосистая часть головы затылок.jpg`

## Что полезно фиксировать

- Каждый очаг отдельно, при постоянном освещении
- По возможности с линейкой/монетой рядом для оценки размера
- Одни и те же ракурсы при повторных съёмках — для сравнения динамики
- Дату съёмки указывать в имени файла

## Назначение

Фотодинамика нужна для дистанционной консультации дерматолога и для объективной
оценки прогрессирования/регресса очагов. При гнёздной алопеции визуальная динамика —
основной способ оценки ответа на терапию.

**Замечание.** Съёмка ведётся для консультации специалиста, а не для ежедневного
самонаблюдения. С учётом обсуждавшегося паттерна тревожного мониторинга частая
самостоятельная фотофиксация может стать самостоятельным источником тревоги.
Разумная частота — раз в 2–4 недели либо перед консультацией.
